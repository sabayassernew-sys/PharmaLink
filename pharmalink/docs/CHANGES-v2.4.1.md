# تحديث 2.4.1 — توسيط النوافذ

- النوافذ المشتركة تستخدم position:fixed وinset:0 وmargin:auto وارتفاعًا بحسب المحتوى لتتوسط الشاشة أفقيًا وعموديًا، بعد أن كانت قواعد تصفير CSS تلغي هامش التوسيط الافتراضي.
- النوافذ الطويلة تلتزم بارتفاع الشاشة المتاح وتتيح تمرير المحتوى.
- قائمة إشعارات الجرس أصبحت نافذة وسطية بنفس المكوّن، مع إغلاق بزر الإغلاق أو Escape أو الضغط خارجها.
- لا تغيير على بيانات المخزون أو صلاحيات العمليات.

التحقق: بناء TypeScript/Vite ناجح، و9 قياسات فعلية لموضع نوافذ الصنف والاستيراد والإشعارات على الكمبيوتر والجوال بوضعين، دون أخطاء JavaScript. فُحص الإغلاق بمفتاح Escape أيضًا.
